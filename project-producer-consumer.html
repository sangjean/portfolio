🔄 원형 다중 버퍼 생산자-소비자 시뮬레이터

운영체제의 스레드 동기화 핵심 주제인 '생산자-소비자 문제'를 시각화한 프로젝트입니다. 멀티스레드 환경에서 발생할 수 있는 교착 상태와 세마포어(Semaphore) 상호작용 매커니즘을 시각적 대시보드로 정밀하게 파악할 수 있도록 모델링했습니다.

프로젝트 개요

C++와 MFC (Microsoft Foundation Class) 라이브러리를 사용해 윈도우 환경에서 실행되는 데스크톱 시뮬레이터로 최초 개발되었습니다. 스레드 동기화 원리를 시각화하기 위해 가상의 Circular Buffer와 세마포어 카운터를 매핑하고, 다중 프로세스의 대기열(Wait Queue) 상태를 실시간 렌더링하는 기법을 도입했습니다. 아래에서 해당 원리를 그대로 이식한 실시간 웹 데모 시뮬레이터를 동작시켜 볼 수 있습니다.

주요 기술적 구현 사항

시나리오 파싱 엔진

`scenario.txt` 파일에 저장된 생산자(P)와 소비자(C)의 작업 지시어를 순차 분석하는 텍스트 시나리오 해석 파서를 구현했습니다. 쉼표 단위 토크나이징 기법을 적용하여 사용자가 사전에 정의한 순서대로 프로세스 생성을 오동작 없이 정렬 제어합니다.

실시간 상태 매핑

메모리 버퍼 공간의 유무(0과 1)와 내부 포인터 인덱스 위치(`in`/`out`), 그리고 현재 락 여부를 감시하는 세마포어 변수(`nrfull`/`nrempty`)를 실시간 대시보드 그래픽 화면에 정밀하게 매핑하여 스레드 경쟁 상황의 가시성을 한 단계 끌어올렸습니다.

렌더링 동기화 타이밍 제어

멀티스레드 시각화 환경에서 발생하기 쉬운 크로스 클래스 렌더링 충돌 현상 및 타이밍 깨짐 오류를 해결하기 위해, 더블 버퍼링 기법과 렌더링 동기화 핸들러를 적용했습니다. 상태 변화가 일어날 때에만 그래픽 리소스를 업데이트하여 메모리 사용량과 드로우 랙을 대폭 감소시켰습니다.
