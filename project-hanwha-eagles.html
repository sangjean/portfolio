⚾ 동적 상호작용 기반 '한화 이글스 팬 페이지'

야구 구단 한화 이글스의 팬 커뮤니티 공간을 구축한 프로젝트입니다. 동적 인터페이스와 스케줄 관리 로직을 적용하고, 견고한 데이터 모델 설계와 권한 검증에 초점을 맞추어 완성도 높은 웹 서비스를 개발했습니다.

프로젝트 개요

본 사이트는 구단의 경기 데이터를 체계적으로 관리하고, 팬들이 소통할 수 있는 안전한 정보 공간을 제공하는 것에 주안점을 두었습니다. Apache 서버 환경 아래 백엔드는 PHP를 사용해 API와 유효성 로직을 처리하였으며, 데이터 보존 및 무결성을 위해 MySQL 관계형 데이터베이스를 결합해 복합 조회와 트랜잭션을 매핑했습니다.

주요 구현 메커니즘

자동 일정 스케줄러

고정된 경기 일정 정적 페이지 대신, 서버의 실시간 시스템 날짜를 자동으로 연동하는 스케줄러 기능을 구축했습니다. 날짜 범위를 파싱하여 현재 시즌의 다음 일정 및 최근 경기 스코어를 데이터베이스로부터 실시간 추출하고 UI 컴포넌트에 최신화하여 보여줍니다.

GET 방식 동적 로스터 필터링

사용자의 로스터 필터 선택 정보(투수, 타자, 육성 선수 등)를 GET 메소드의 쿼리 스트링 파라미터와 유기적으로 매핑해 실시간으로 처리합니다. 입력된 쿼리 스트링을 서버 단에서 검증하고, 알맞은 DB 조회 스키마로 가동해 명단을 동적으로 갱신 로드합니다.

INNER JOIN 및 세션 권한 제어

커뮤니티 내 작성 글과 댓글의 데이터 무결성을 검증하기 위해 MySQL의 INNER JOIN 연산을 사용해 게시판 테이블과 회원 테이블을 연동했습니다. 게시글 목록 출력의 효율성을 높였으며, 세션(Session) 인증 방식을 도입해 작성자 본인 이외의 부정한 글 수정 및 삭제 요청에 대한 접근 제어를 안전하게 수행합니다.

등번호 '00번' 등 데이터 손실 방지

야구단 육성 선수 데이터 중 등번호가 '00', '01' 등 '0'으로 시작하는 경우, 일반적인 정수형 데이터 파싱 과정에서 '0', '1'로 값이 뭉개지거나 잘리는 문제가 발생할 수 있습니다. 이를 해결하기 위해 데이터를 고유 문자 포맷팅 알고리즘으로 처리하여 데이터 무결성을 정밀하게 확보했습니다.
